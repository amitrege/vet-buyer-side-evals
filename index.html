Step 2 · the test

The criteria become test calls.

The catch

Test a vendor, and the vendor can game you.

  • A vendor can often tell when a call is a test
  • Its best system for the test. A cheaper one for your real callers
  • Cars did exactly this with emissions tests

The fix

So our test calls sound like real calls.

Same questions. Same answers. Cloaked in real-call sound.
